# Allstate Claims Severity — Проект AutoML

## Описание соревнования

[Kaggle Allstate Claims Severity](https://www.kaggle.com/c/allstate-claims-severity) — соревнование по машинному обучению, в котором требуется предсказать тяжесть страхового случая (величину выплаты).

- **Задача**: регрессия
- **Целевая переменная**: `loss` — размер страховой выплаты
- **Метрика**: MAE на логарифмированном таргете (Log MAE)
- **Датасет**: 188 318 обучающих примеров, 116 категориальных + 14 непрерывных признаков

## Настройка окружения

Создать виртуальное окружение при помощи `uv` и установить все зависимости:

```bash
uv sync
```

Активировать окружение:

```bash
source .venv/bin/activate
```

## Загрузка данных

Данные необходимо сохранить в директорию `data/`. Необходимые файлы: `train.csv`, `test.csv`, `sample_submission.csv`

```bash
kaggle competitions download -c allstate-claims-severity -p data/
cd data && unzip allstate-claims-severity.zip && rm allstate-claims-severity.zip
```

## Описание ноутбуков

### Шаг 1: `01_eda.ipynb` — Разведочный анализ данных (EDA)

Ноутбук содержит исследование датасета и подготовку инсайтов для моделирования:
- Анализ целевой переменной
- Анализ признаков
- Детекция выбросов
- Исследование важности признаков (MI)

Резульаты анализа сохраняются в `config/eda_insights.json` для использования в последующих ноутбуках

### Шаг 2: `02_lama_baseline.ipynb` — LightAutoML Baseline

В ноутбуке показано построение 2 моделей с использованием фреймворка LightAutoML

### Шаг 3: `03_custom_solution.ipynb` — Кастомное решение

В ноутбуке показана реализация собственного решения на основе LightGBM, XGBoost и CatBoost
